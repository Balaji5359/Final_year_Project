Intelligent Airport Gate Assignment Using Machine Learning and Multi-Objective Optimization
Final Year Project Report
Author: R Balaji
Abstract
Airport gate assignment affects passenger movement, turnaround reliability, and ground emissions. This report presents an end-to-end proof-of-concept system that combines synthetic data generation, delay prediction using machine learning, and constrained optimization using a genetic algorithm. The dataset contains realistic flight and gate attributes with overlapping schedules. Model comparison across Linear Regression, Random Forest, and optional 
XGBoost
 is performed using RMSE and MAE. The best model is integrated into the optimization fitness function to penalize predicted delays while minimizing walking distance, taxiing distance, and CO2 proxy emissions. A 
Streamlit
 dashboard is built for transparent demonstration. Results from the current run indicate measurable improvement in CO2 proxy and predicted delay versus baseline, with an expected trade-off in walking distance due to competing objectives. The solution is explainable and academically suitable as a prototype, not as a production deployment.
1. Introduction
Airports operate under tightly coupled spatial and temporal constraints. A gate assignment decision must satisfy aircraft compatibility, flight type restrictions, and non-overlapping occupancy windows at each gate. Conventional static methods cannot always adapt to dynamic operating conditions and uncertainty in delays. This study proposes an intelligent framework where machine learning estimates operational uncertainty and optimization searches for better assignments under multiple objectives.
Key contributions are: (
i
) configurable synthetic data generation (20-60 flights), (ii) automatic model selection for delay prediction, (iii) multi-objective genetic algorithm optimization with feasibility checks and fallback logic, and (iv) an interactive dashboard for inspection of metrics and assignments.
2. Literature Review and Research Gap
Prior research on Airport Gate Assignment Problem (AGAP) includes deterministic optimization, heuristics, and metaheuristics. Deterministic methods provide strong optimality guarantees but may become computationally expensive under nonlinearity and uncertainty. Heuristics are fast but can produce lower-quality allocations. Genetic algorithms are widely used for large combinational spaces due to robust global search 
behavior
.
Research gap: most small-scale academic prototypes either ignore uncertainty or optimize only a single objective. Environmental metrics are often detached from assignment logic. This report bridges the gap by integrating delay prediction inside the optimization fitness and reporting operational and environmental outcomes together.
3. Problem Formulation
Constraints:
1) One flight to one gate: sum over g of x(
f,g
) = 1 for all flights.
2) Gate compatibility: gate size must be greater than or equal to aircraft size.
3) Gate type compatibility: domestic flights to domestic-capable gates and similarly for international flights.
4) No overlap at same gate: if two flights overlap in time, they cannot share one gate.

Phase C: Optimization Algorithm
Chromosome encoding: each gene index represents one flight, and the gene value is a selected 
gate_id
.
Fitness components: passenger walking cost, taxiing cost, CO2 proxy, and predicted delay penalty.
CO2 proxy formula:
CO2_total = sum over flights of 
fuel_burn_rate
 * (
taxi_distance_to_runway
 + 
distance_from_runway
(gate)) * (1 + 
predicted_delay
/60).
Genetic procedure: initialize population, evaluate fitness, keep elite set, crossover, mutation, and early-stop when no improvement. If final candidate is infeasible, apply heuristic first-fit fallback.
Algorithm (Pseudo Steps)
1. Generate initial population with baseline and random compatible assignments.
2. For each chromosome, compute normalized objective terms and constraint penalties.
3. Sort by fitness (lower is better) and preserve elite individuals.
4. Create offspring using one-point crossover and mutation by compatibility lists.
5. Repeat for fixed generations or stop early on stagnation.
6. Return best feasible solution and produce baseline-vs-optimized comparison.

7. Conclusion and Future Work
This report presents a complete academic prototype for intelligent airport gate assignment. The integration of predictive 
modeling
 and constrained optimization provides measurable improvement in key metrics while maintaining explainability. The framework is suitable for demonstration and comparative experimentation with small datasets.
Future work includes: integrating real operational datasets, adding disruption recovery and robust scheduling logic, benchmarking against exact methods such as MILP, and extending objective definitions with richer passenger flow and turnaround constraints.
8. Limitations
1) Synthetic data does not reflect full airport operational complexity.
2) CO2 metric is a proxy for comparative analysis.
3) Small sample sizes are useful for explainability but not production generalization.
4) Model quality depends on generated feature realism.
